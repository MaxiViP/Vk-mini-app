# План развития VK Mini App AI Assistant

## 1. Цель проекта

Развить VK Mini App из AI-чата в полноценное приложение с готовыми сценариями, шаблонами, инструментами, ассистентами, бонусами, тарифами и информационными страницами.

Главная идея: добавлять функции постепенно, но сразу закладывать архитектуру так, чтобы любую функцию можно было включить или скрыть через feature flags.

---

## 2. Главные принципы разработки

1. Не ломать существующий чат.
2. Не удалять текущую функциональность.
3. Все новые функции подключать через feature flags.
4. Если функция не готова, она должна быть скрыта.
5. Если страница добавлена, но не используется, она не должна мешать работе приложения.
6. Сначала делать frontend-заглушки, потом backend.
7. Данные для первых MVP можно хранить на фронте в `front/src/data`.
8. Не менять бизнес-логику оплат без отдельной задачи.
9. Не менять AI backend без отдельной задачи.
10. Не менять авторизацию без отдельной задачи.
11. Каждая задача должна быть маленькой и проверяемой.
12. После каждой задачи проект должен запускаться без ошибок.

---

## 3. Feature flags

Создать файл:

```txt
front/src/config/features.ts
```

Содержимое:

```ts
export const FEATURES = {
  homePage: true,
  promptCatalog: true,
  aiTools: true,
  assistants: false,
  bonuses: false,
  referrals: false,
  publicCollections: false,
  changelog: false,
  safetyPage: true,
  helpPage: true,
  tariffsPage: true,
  feedbackPage: true,
  sharing: false,
  dailyTasks: false,
  promptFavorites: false,
  customAssistants: false,
}
```

Назначение:

- `homePage` — новая главная страница.
- `promptCatalog` — каталог AI-шаблонов.
- `aiTools` — быстрые AI-инструменты.
- `assistants` — страница ассистентов.
- `bonuses` — бонусы.
- `referrals` — реферальная система.
- `publicCollections` — публичные подборки.
- `changelog` — страница обновлений.
- `safetyPage` — страница безопасности и приватности.
- `helpPage` — страница помощи.
- `tariffsPage` — отдельная страница тарифов.
- `feedbackPage` — обратная связь.
- `sharing` — кнопки шаринга.
- `dailyTasks` — ежедневные задания.
- `promptFavorites` — избранные шаблоны.
- `customAssistants` — пользовательские ассистенты.


- Если пользователь пытается открыть отключенную страницу, нужно перенаправлять его на `CHAT` или `HOME`.
