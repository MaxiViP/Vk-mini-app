# 🤖 VK Mini App: Чат с LLM (облачные + локальные модели)

Мини-приложение для ВКонтакте, которое позволяет общаться с различными языковыми моделями: облачными (OpenAI, Groq, OpenRouter) и локально обученными. Поддерживает стриминг ответов, переключение моделей, заметки, профиль пользователя и автоматический fallback при ошибках.

![Скриншот](screenshot.png) <!-- добавьте скриншот по желанию -->

## 📋 Возможности

- ✅ **Чат в стиле Telegram** — аватарки, пузыри с хвостиками, адаптив.
- ✅ **Поддержка нескольких LLM** — OpenAI, Groq, OpenRouter, Cloudflare AI Gateway, локальные модели (OpenAI-совместимые).
- ✅ **Стриминг ответов** — текст появляется по мере генерации.
- ✅ **Markdown + подсветка кода** — формулы, таблицы, списки, код (через `marked` + `highlight.js`).
- ✅ **Автоматический fallback** — если текущая модель не отвечает, перебирает все доступные.
- ✅ **Система заметок** — сохраняйте ответы модели в выезжающую панель, копируйте, экспортируйте в TXT.
- ✅ **Профиль пользователя** — данные из VK, баланс запросов, пополнение.
- ✅ **Выбор модели** — два дропдауна: облачные / локальные.
- ✅ **Адаптивная вёрстка** — корректно отображается на телефонах и ПК.
- ✅ **VK Bridge** — авторизация через VK, получение данных пользователя.

## 🚀 Установка и запуск

### Требования

- Node.js 18+
- npm или yarn
- Аккаунт VK (для создания мини-приложения)
- API-ключи для используемых LLM (OpenRouter, Groq и т.д.)

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-username/vk-llm-chat.git
cd vk-llm-chat

npm install
npm run dev
```
